# DataNova-Tech

DataNova-Tech is a structure focused on Data Science, Artificial Intelligence, and Data Engineering.

We design data-driven solutions to collect, structure, analyze, and leverage data in order to address real-world challenges and support decision-making.

## Areas of expertise

- Data Science
- Artificial Intelligence
- Data Engineering
- Data Analytics
- Machine Learning
- Data Visualization

## Projects

This repository contains the DataNova-Tech website and technical projects developed around data and artificial intelligence.

### California Housing Price Prediction

A machine learning project for predicting median housing values in California using socio-economic and geographical features.

**Technologies:** Python, Pandas, Scikit-learn, Random Forest

**Results:** R²: 0.8064 · MAE: 0.3267 · RMSE: 0.5037
