DATA SCIENCE · MACHINE LEARNING

California Housing Price Prediction

Développement d'un modèle de Machine Learning capable de prédire la valeur médiane des logements en Californie à partir de données socio-économiques, démographiques et géographiques.

Plusieurs modèles ont été comparés, notamment la régression linéaire, le Random Forest et le Gradient Boosting. Le Random Forest a obtenu un R² de 0,806 sur les données de test.
